# Grill Me

설치된 `grilling` 스킬이 있으면 그 SKILL.md를 읽고 인터뷰를 진행한다. 플러그인 slash command를 실행하거나 다른 서비스에 위임하지 않는다.

단독 설치된 경우 다음 절차로 같은 핵심 동작을 수행한다.

1. 적용되는 AGENTS.md와 계획·관련 코드를 조사한다. 위키가 있으면 index → overview → 최신 log를 먼저 읽는다. 직접 확인할 수 있는 사항은 사용자에게 묻지 않는다.
2. 목적·성공 기준과 되돌리기 비싼 가정을 우선 정리한다. 미결 중 하나만 질문한다. 가능하면 2~3개의 결과 중심 선택지와 권장안을 제공한다.
3. 현재 모드에서 허용되는 질문 도구를 사용한다. `request_user_input`이 허용되지 않으면 비동기 도구 또는 일반 질문을 사용한다. 지원하지 않는 필드를 넣지 않는다.
4. 답변을 받은 뒤 다음 갈림길을 탐색한다. 무응답·기본 선택·시간 경과를 답이나 승인으로 해석하지 않는다. 기다리는 동안 독립적인 조사만 한다.
5. 결정이 모이면 요약하고 남은 가정과 검증 방법을 확인한다. 인터뷰만 요청받았다면 합의 전 구현하지 않는다. 사용자가 이미 준 명확한 실행 권한은 반복해서 묻지 않는다. 중단 요청은 따른다.

기록은 사용자 요청과 로컬 위키 정책에 따르고 읽기 전용 요청이면 파일을 쓰지 않는다. Jira 생성이나 외부 게시 권한을 인터뷰에서 추론하지 않는다.
