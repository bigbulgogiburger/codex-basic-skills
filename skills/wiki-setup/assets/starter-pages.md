# 초기 페이지 작성 예시

아래는 네 파일의 시작점이다. 날짜·설명·경로는 실제 조사 결과로 채운다. 기존 허브에 템플릿을 덮어쓰지 않는다. 표의 예시 행은 실제 파일로 교체하거나 비워 둔다.

## wiki/index.md

```markdown
# 위키 색인

- [개요](overview.md) — 목적과 확인된 맥락
- [원본 인벤토리](catalog.md) — 파일과 인제스트 상태
- [작업 이력](log.md) — 최근 변경과 미해결 사항

## 엔티티

아직 합성된 페이지 없음.

## 개념

아직 합성된 페이지 없음.

## 소스 심층 요약

아직 합성된 페이지 없음.
```

## wiki/overview.md

```markdown
# 개요

목적: 사용자가 지정한 목적을 기록한다. 지정되지 않았으면 미확인.
범위: 이번에 확인한 폴더 범위와 아직 조사하지 않은 범위.
초기 상태: 위키 구조만 준비됨. 원본 내용의 전체 인제스트는 수행하지 않음.

[색인](index.md) · [원본 인벤토리](catalog.md) · [작업 이력](log.md)
```

## wiki/catalog.md

```markdown
# 원본 인벤토리

집계 기준일: 실제 작업일
조사 범위: 실제 열거한 경로, 또는 미조사
제외: wiki/, AGENTS.md, CLAUDE.md, .git/, .agents/, .codex/, .claude/, 도구·캐시·잠금 파일·별도 생성 산출물
총계: 실제 열거 전에는 미확인. 미인제스트 파일도 총계에는 포함.

| 원본 경로(루트 기준) | 반영 상태 | 반영 페이지 | 비고 |
|---|---|---|---|

반영 상태: 미인제스트 / 부분 반영 / 반영 완료 / 읽기 실패.
파일 수와 위키 페이지 수는 다르다. 무효화된 원본도 실물이 있으면 인벤토리에 유지한다.

[색인](index.md)
```

## wiki/log.md

```markdown
# 작업 이력

아래에 날짜순으로 추가한다. 기존 항목은 수정·재정렬하지 않는다.
```

그 뒤 실제 날짜의 setup 항목을 append한다. 생성 파일, 기존 원본 보존 여부, 조사 범위, 남은 인제스트를 기록한다.
